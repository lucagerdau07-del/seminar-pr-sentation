# seminar-pr-sentation

`Percy_Julians_Forschungsweg.html` ist die Seminarpräsentation als einzelne Datei. Sie läuft im Browser (Internet nötig, weil three.js von cdnjs geladen wird).

Die Datei enthält sich selbst noch einmal als eingebettete Vorlage, damit sie sich als Artifact mit eigenen Fotos neu speichern kann. Nach jeder Änderung an der HTML-Datei deshalb einmal ausführen:

```
python3 werkzeug/vorlage_erneuern.py
```
